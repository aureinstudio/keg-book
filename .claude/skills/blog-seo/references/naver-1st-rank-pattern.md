## 2) 통념 vs 실측

### ❌ 통념 "AI 생성 이미지는 패널티"

1위 글의 콘텐츠 이미지 11장 중 **7장이 ChatGPT 생성**. 파일명도 `ChatGPT_Image_2026년_3월_11일_*.png` 그대로. 네이버 알고리즘은 이미지 메타로 AI 판정을 못 한다. 본문이 좋으면 AI 이미지여도 1위 가능.

### ❌ 통념 "본문 3,000자 이상 권장"

1위는 2,500자. 2,000–3,000 사이가 sweet spot. 3,500 초과는 한계효용 감소.

### ❌ 통념 "영상/움짤 가산점 필수"

1위에 영상 0개. 정적 콘텐츠로도 1위 가능.

### ✅ 진실 "검색의도 = 제목 = 첫 문장 일치"

가장 강한 신호. 1위는:
- 검색어 (가정): "비전공자 웹디자이너 취업"
- 제목: "비전공자인데 웹디자이너 취업 가능할까? ..."
- 첫 문장: "❓ 비전공자인데 웹디자이너 취업 가능할까요?"
- OG description: 첫 문장과 동일

3중 매칭. D.I.A.+ 의도 분석 최고가점.

### ✅ 진실 "1인칭 narrative + 체크박스 ✔"

이 두 가지가 D.I.A.+ 원문성 + 모바일 가독성을 동시에 가산. 일반론은 0%, 본인 사례는 100%.

### ✅ 진실 "AI 한국어 어휘 회피가 결정적"

영어 AI tell(em-dash, "furthermore")보다 한국어 어휘 회피가 더 강력한 신호. 1위는 "또한·따라서·결론적으로·궁극적으로·한편" **0회**.

## 3) 한국어 AI 어휘 블랙리스트

**접속어/전환 (가장 위험)**

| 피해야 할 어휘 | 자연스러운 대체 |
|---------------|----------------|
| 또한 | 그리고, 그 외에도, "~도 있어요" |
| 따라서 | 그래서, "그러다 보니" |
| 그러므로 | 그래서 |
| 결론적으로 | 정리하자면, "지금 돌이켜보면" |
| 궁극적으로 | 결국, 마지막엔 |
| 핵심적으로 | 가장 중요한 건 |
| 뿐만 아니라 | "~도 그렇고", "~까지 챙기면" |
| 즉, | 다시 말해, "그러니까" |
| 한편, | 그런데, "그러는 동안" |
| 예를 들어 | "예를 들면", "이런 식이에요" |

**과장 형용사**

| 피해야 할 어휘 | 대체 |
|---------------|------|
| 최고의, 최상의 | (사용 자제) — 1인칭 후기로 우회: "제가 써본 중에는 가장 좋았어요" |
| 필수적인 | "있으면 좋은", "도움이 됐던" |
| 혁신적인 | "새로운", "기존과 다른" |
| 완벽한 | "충분한", "만족스러운" |
| 압도적인 | (사용 자제) |

**상업적 단어 (광고성 패널티)**

```
절대 금지: 할인, 이벤트, 무료증정, 특가, 최저가, 구매, 쿠폰,
          적립, 한정수량, 단독, 독점, 사은품
대체:    "공식몰에서 확인 가능", "정보는 아래에서",
          "관심 있으신 분들은 살펴보셔도 좋을 것 같습니다"
```

**클릭베이트 단정 (D.I.A. 감점)**

```
금지:  "이것만 알면 끝", "100% 효과", "절대 후회 안 함",
       "무조건 추천", "모든 학부모 필독"
대체:  "제 경우엔 도움이 됐어요", "써본 입장에서는",
       "비슷한 고민이 있으시면 참고하세요"
```

## 4) 1위 패턴 6가지 (실행 체크리스트)

### Rule 1: 첫 문장 = ❓ 의문문 + 검색어 그대로

```
❌ "오늘은 OOO 교재에 대해 알아보겠습니다."
✅ "❓ 중1 영어 듣기, 어떤 교재로 시작해야 할까요?"
```

### Rule 2: 본문 2,200–2,800자

`bodyText.replace(/\s+/g, "").length` 기준. 3,000 넘기지 말 것.

### Rule 3: 소제목 5–6개로 시간 흐름 narrative

```
권장 패턴:
  1. [배경/계기]    "OOO를 시작하게 된 이유"
  2. [현장/과정]    "OOO 수업/교재 첫 인상"
  3. [감정 hook]   "기억에 남는 한 순간"
  4. [디테일/노력]  "공부하면서 했던 노력"
  5. [결과]        "한 학기 후 변화"
  6. [성찰/CTA]    "비슷한 고민이 있으신 분들께"
```

### Rule 4: ✔ 체크박스 리스트 3–4곳

`<ul>` 대신:
```html
<p>✔ 매일 30분 루틴<br/>
✔ 단원 끝나면 노트 정리<br/>
✔ 주 1회 받아쓰기</p>
```

모바일에서 한 화면 스캔이 쉬워 체류 시간 ↑.

### Rule 5: 1인칭 마커 8회 이상 분산

`/저도|제가|저는|느꼈|느낌|돌이켜|직접|써본|솔직히|개인적으로/`

검사기준: 본문 전체에서 8회 이상. 한 문단에 몰리지 말고 분산.

### Rule 6: 금지 어휘 0회

위 §3의 한국어 AI 어휘 + 상업어 모두 본문에서 한 번도 등장하지 않을 것.

## 5) KEG 교재 마케팅 적용 예시

### Before (현재 AI 톤)

```
제목: 중학교 1학년 영어 듣기 교재 OOO 추천! 최고의 학습 도구
첫 문장: 또한 OOO 교재는 학생들에게 필수적인 도구입니다.
       따라서 많은 분들이 추천하고 있습니다.
```

### After (1위 패턴 학습)

```
제목: "중1 영어 듣기 막막했는데 이 교재로 한 학기 만에 따라잡았어요"

첫 문장: "❓ 중학교 영어 듣기, 어떤 교재로 시작해야 할까요?
        저도 처음엔 이 고민부터 했어요."

소제목 6개:
  1. 중1 1학기, 영어 듣기에서 막혔던 순간
  2. 여러 교재를 비교해본 과정
  3. 단원 구성이 좋았던 부분
  4. 매일 30분 루틴으로 했던 노력
  5. 한 학기 후 변화 — 점수와 자신감
  6. 듣기 교재 고민 중인 분들께

체크박스:
  ✔ 매일 30분 루틴
  ✔ 단원 끝나면 노트 정리
  ✔ 주 1회 받아쓰기

CTA: "교재 정보가 궁금하신 분들은 아래에서 확인해 보셔도
     좋을 것 같습니다 :)"
```

## 7) 운영 권고

- **재측정 주기:** 분기마다 1회 — 네이버 알고리즘은 분기 단위로 큰 변화. 1위 글을 다시 뽑아 패턴 갱신.
- **검색어별 확인:** 본 문서는 "비전공자 웹디자이너 취업" 검색의 1위. KEG 교재 키워드("중1 영어", "수능 국어" 등)별로 1위 글을 별도 분석해 카테고리별 패턴 보강 권장.
- **블로그 신뢰도(C-Rank):** 단일 글 패턴만으로 충분치 않음. 같은 카테고리(교육)에 주 2–3회 꾸준히 발행하는 게 C-Rank 가산점의 진짜 동력.
