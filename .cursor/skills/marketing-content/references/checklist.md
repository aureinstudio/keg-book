# 마케팅 콘텐츠 — 채널별 체크리스트 (참고)

`SKILL.md` 본문을 짧게 유지하기 위한 보조 표다.

## 길이 가이드 (대략)

| 채널 | 권장 |
| --- | --- |
| 블로그 | 800~2500 단어(캠페인에 맞게 조정) |
| 인스타 캡션 | 900~2200자(공백 포함) 전후, 해시태그 별도 |
| Threads | 포스트당 1~4문장 |
| 메일리 | 섹션 3~6개, Q&A당 답변 2~6문단 |
| 카드뉴스 | 슬라이드당 프롬프트 40~120 단어 + 비율 명시(예: 1080×1350) |

## 카드뉴스 프롬프트에 넣을 공통 지시

- 브랜드 색·로고 사용 여부(있으면 설명만, 바이너리 첨부는 사용자)
- 텍스트 최소화, 고대비, 모바일 가독
- 아동·학습 장면은 과장·불안 조장 금지

## 메일리 붙여넣기 시

- YAML frontmatter는 에디터가 지원하지 않으면 제거
- `이미지 출처` 줄은 실제 출처가 확정된 경우만 유지
