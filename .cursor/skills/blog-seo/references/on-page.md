# 온페이지 SEO 체크리스트 (블로그)

출력 전에 빠르게 훑는다. 상세는 `SKILL.md` 본문.

## 필수

- [ ] 검색 의도(정보/교육/탐색)가 한 글에 하나로 정리됨
- [ ] 제목 후보 1~2개 + 메타 설명 + 슬러그 제시됨
- [ ] H2 순서가 질문 흐름과 일치(위에서 아래로 읽어도 이해됨)
- [ ] 첫 화면(폴드) 안에 핵심 답의 일부가 보임
- [ ] 키워드 스터핑 없음(같은 구문 반복 3회 이상 연속 금지 권장)

## 권장

- [ ] FAQ 3문항 이상(정보형 글)
- [ ] 내부 링크 자리 2곳 이상 `{{내부:}}`
- [ ] 이미지 삽입 위치 + `alt` 초안
- [ ] 표 또는 번호 목록으로 절차·비교 정리

## 슬러그 예시 (영문)

| 주제 키워드 | 슬러그 예 |
| --- | --- |
| 중등 영어 교재 선택 | `middle-school-english-textbook-guide` |
| 독해 점수 올리기 | `reading-comprehension-study-tips` |

## 메타 설명 금지 패턴

- "최고의", "무조건", "100%" 등 과장
- 본문과 무관한 키워드 나열
- 전화번호·가격만 나열(정보 가치 없음)
